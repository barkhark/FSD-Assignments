# Assignment Descriptions

## Assignment 1 – Student Registration

A web application for registering student details and storing them in a MySQL database using JDBC.

---

## Assignment 2 – Login Authentication

A secure login system that validates user credentials from the database using Servlets and JDBC.

---

## Assignment 3 – Student Result System

Displays student marks, percentage, grade and result after fetching data from the database.

---

## Assignment 4 – Employee Salary Calculator

Calculates employee salary based on basic salary, allowances and deductions.

---

## Assignment 5 – Shopping Cart

A shopping cart application that allows users to add products, calculate totals and manage purchases.

---

## Assignment 6 – Library Management

Library management system for maintaining books and handling issue/return operations.

---

## Assignment 7 – Employee Management

Employee Management System supporting Create, Read, Update and Delete (CRUD) operations.

---

## Assignment 8 – Feedback Management

Collects, stores and displays user feedback using Java, JSP, Servlets and MySQL.

---

## Assignment 9 – Student Attendance

Attendance management system for recording and displaying student attendance.

---

## Assignment 10 – Course Registration

A complete Course Registration System with the following features:

- Student Login
- Course Listing
- Register for Courses
- Prevent Duplicate Registration
- View Registered Courses
- Logout
- Database Connectivity using JDBC
